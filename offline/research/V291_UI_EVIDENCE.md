# 2.9.1 r17 UI 證據與人工檢查範圍

整理日期：2026-10-25。此頁補充 [UI素材與校準實作](../v291/restored/UI_ASSET_RECOVERY.md)，保存本機來源稽核的範圍、統計分母與報告判讀方式。既有來源S166–S172及新增S174–S182、S184見 [來源清單](sources.json)；本次只核對文件、JSON與來源程式，未重跑遊戲測試。

r17候選的既有報告身分為889,510,545 bytes，APK SHA-256 `93eb5e82c3f7bce10c8c55c31cfd99182dbaf414a308e2dd6d8383f91fa29705`，套件 `jp.gungho.dg.offline291.restored`。下述結果只對應此候選，不能當作其他r17版本的證據。

| 本機來源 | 稽核範圍 | 結果及界線 |

以上是已安裝本機來源的範圍，不能延伸成網路上或其他備份不存在裁切表。兩包DG0圖集只提供具名像素；不把後期程式、角色主資料或帳號資料加入2.9.1。完整來源指紋與矩形留在S177。

圖塊必須同時符合原生UIAtlas與TexturePacker矩形才採用。新增34個門縮圖由248×152正規化為既有207×131契約；105個地塊維持128×128。原93個門圖與111個地塊不覆寫。未知名稱不在第一圖集建立替代圖塊，才能讓原生搜尋繼續查後面的圖集。

## 146個HUD人工檢查項目如何分組

原595角色維持原裁切；新增1,153角色有1,007個使用校準視窗，146個使用整體可見立繪。由S170逐列重算的互斥分類如下：

| 原因組合 | 角色數 |
| --- | ---: |
| 只有頭像匹配信心不足 | 68 |
| 只有素材角色的整體構圖 | 59 |
| 同時屬於上述兩項 | 18 |
| 巨型角色構圖 | 1 |
| 合計 | 146 |

若按原因標籤分別計數，低匹配為86、素材角色為77、巨型角色為1，因18個重疊，不能相加當作146個不同角色。這份清單不是146個已確認顯示錯誤：低匹配需看取景，素材／巨型角色需判斷整體構圖是否適合原生遮罩。

報告用原595角色的官方參數作參考，495個通過匹配門檻，進化家族與共用draw_id保持在同一折，五折各99個。對應 `party0..4 → img4..0`：

| 隊伍位置 | 重疊度IoU中位數 | 中心誤差／原版邊長中位數 |
| --- | ---: | ---: |
| party0 | 79.2% | 5.7% |
| party1 | 79.0% | 4.9% |
| party2 | 80.4% | 4.5% |
| party3 | 79.6% | 4.8% |
| party4 | 77.9% | 4.4% |

這是參考集分組驗證，並非1,007個新增角色與官方裁切的比對，也不是最差誤差保證。預覽只畫來源矩形，不模擬原生多邊形遮罩。人工檢視時應記錄角色ID、隊伍位置及實際遮罩；1,007個校準結果也沒有自動免除實機檢查。

## 方法比較的基準不能混用

| 證據 | 比較基準 | 既有結果 |
| --- | --- | --- |
| S179 `original-methods.txt` | 原2.9.1遊戲組件→r17 | 7,511個方法未改，97個允許修改 |
| S178 `expanded-extra-tests.json` | 已含離線修復的r10→r17 | 7,618個方法未改，1個允許修改 |
| S168 UI檢查 | r17的隊伍建立方法 | 移除7個返回點的窄UI掛鉤後，逐指令恢復原方法 |

比較基準由 [一般測試入口](../v291/playable/test.py) 與 [擴充檢查入口](../v291/restored/verify_more.py) 確認。後者只允許 `InGameManager::StepFuncReadyCreateParty()` 差異；「允許修改」不表示整個方法未改，而是修改在預期名單內，再由專用檢查核對掛鉤。

S184及S174內嵌的較早還原摘要仍寫「r10到本版7,619個原生方法全部相同」，已不符合r17的UI掛鉤結果；其末尾「請使用r12」也是保留的舊說明。判讀r17應採最新的7,618＋1結果與r17候選身分，不能照搬舊摘要。原始報告保留不覆寫，以維持可追溯性。

## 版本與驗證界線

r14、r15、r16的STATUS均明列為未交付／未安裝的中間候選，後續採r17；不是三次實機成功紀錄。r13只有既有啟動／登入邊界證據，r17的 `handoff.json` 則明列 `android_tested=false`、`device_operated=false`。

r17既有受管報告、來源像素與原生方法檢查不能替代門圖位置、地塊縮放／翻牌、五位置遮罩、動畫及記憶體的Android驗證。r12記憶體閃退的診斷與後續修正見 [診斷摘要](DIAGNOSTIC_FINDINGS.md)；完整建置依賴與候選入口見 [還原設定](../v291/restored/README.md)。
