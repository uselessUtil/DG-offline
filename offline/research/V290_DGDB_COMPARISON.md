# 2.9.0 r17 既有內容與 DGDB 比對

整理日期：2026-10-25（Asia/Taipei）。本頁保存本機 `2.9.0-r17-existing-vs-dgdb-20261025` 調查的結論，來源 S96–S103、S110 見 [來源清單](sources.json)。本次整理只核對既有報告、分析方法及統計一致性，未重新啟動遊戲組件或執行 Android 戰鬥。

## 比較對象與方法

此調查以 **r17 簽署 APK 組件初始化後匯出的有效主資料**對照 DGDB，不只看原 APK 的 TextAsset，也不將 DGDB 額外收錄的後期內容加入分母。

| 輸入 | SHA-256 |
| --- | --- |
| 2.9.0 r17 候選 APK | `b8caed0f1f5c6b34e1285db7dffcf3584436a2980393aa88324e18faa72b6e8f` |
| DGDB `dump_20170921.sql` | `a507e0d519a70bab7617c7e37bd9f32b2a75894eb8bdbbffffa0c5b4b259d25f` |

DGDB 的年代與欄位缺口見 [主資料整理](MASTERDATA.md)。它是後期資料站彙整，不是 r17 的權威修正表；相同 ID 可能已改名、換角色或重編內容。

調查分兩層：先比較同 ID 的共通純量欄位（排除網站時間及陣列），再限縮角色、關卡、敵人的指定核心欄位。核心統計不包含完整技能效果、所有區域規則或遞迴關聯。因此「相同」只表示本次比較欄位相同。

## 角色：595 個都能對應，但數值並非同一時期

| 範圍 | 有差異 | 相同 |
| --- | ---: | ---: |
| 共通純量欄位，包含文字／技能引用 | 165 角 | 430 角 |
| 選定核心數值／類型欄位 | 144 角 | 451 角 |

全部 595 角的圖鑑號及資源字串一致；最大 HP 有 107 角、最大攻擊 123 角、Cost 67 角、初始 HP 52 角、初始攻擊 53 角不同。這些欄位的角色集合重疊，不能把差異數相加當成受影響角色數。

隊長技引用 19 角、必殺技引用 21 角、兩個普通技與被動技引用各 12 角不同。引用相同也不證明技能定義或執行效果相同。

- 炎甲士アカネ：最大 HP 979→1279、最大攻擊 516→816。
- リヴァイ兵長：Cost 15→25、最大 HP 1768→2743、最大攻擊 1457→2257；DGDB 名稱另為リヴァイ兵士長。
- 光才カルネアデス：最大 HP 3450、最大攻擊 2280、Cost 25 與技能 ID 相同，但 r17 已有原生狀態配接，不能用舊值欄位逐欄相等判斷技能倍率。

箭頭均為 r17→DGDB，不表示建議套用後者。保留舊內容時應維持 r17 來源數值，修正配接語意與匯入後期平衡值是兩件不同的工作。

| --- | --- |
| 383 | 1883 |
| 389 | 1884 |
| 390 | 1885 |

這是比對對照表，沒有改寫遊戲 ID 或存檔。與 1.0.6→舊快取的魔禁 420–424→436–440 是不同映射，不能混用。

完成映射、排除 reserve 後，392 筆任務中 179 筆指定核心欄位不同、213 筆相同：體力 86、通關經驗 82、通關金幣 73、相鄰格連戰 96、保證角色 3、保證角色等級 6 筆不同。例如風の試練：初級體力 5→0；150 萬下載紀念五關的區域與 Boss 群組引用也不同。

目前啟用關卡引用 762 筆啟用樓層，對應的 DGDB 關卡均有樓層。比較按「對應關卡 → `under` 類型 → 表內順序」排列，`under` 不是唯一樓層號，不能硬以全域 floor ID 配對。

報告列出 360 關至少一個被比較的樓層欄位不同；唯一樓層數差異是教學首關，r17 由專用流程生成、主表為零筆，DGDB 為一筆。這不表示 r17 缺少可玩的教學。生成模式、敵群、陷阱與物品的 ID 差異仍須連表解讀；此順序比較也不是完整的關卡行為等價驗證。

上述「392 關都有 DGDB 樓層」只針對 r17 現有內容，不推翻 DGDB 全庫有 1,791 個關卡目錄缺樓層的較早調查。

## 敵人：同 ID 可能已換角色

| 比較範圍 | 記錄數 | 有差異 | 相同 |
| --- | ---: | ---: | ---: |
| 全部非零敵人，共通純量欄位 | 2,587 | 252 | 2,335 |
| 全部敵人，選定核心欄位（不含角色 ID） | 2,587 | 251 | 2,336 |
| 限角色 ID 相同，再比較核心欄位 | 2,557 | 222 | 2,335 |
| 有效樓層／連鎖／關聯亂入能追到的敵人，核心欄位 | 2,108 | 158 | 1,950 |

所有 2,587 個敵人 ID 都存在於 DGDB，但其中 30 筆 `chara_id` 不同；例如敵人 105090 的角色由 56 變為 273，不能稱作同一敵人的單純 HP 調整。核心欄位比對不含 `chara_id`，因此 251 與 252 的差別不是報告矛盾。

全體設定中 HP 229、攻擊 234、防禦 76、回合 10、掉落角色 51 筆不同，仍有重疊。2,108 筆可追溯敵人的統計也沒有先排除角色替換；關聯存在不等於當下活動日期會觸發，亦不等於已實際遭遇。

新 schema 的 `drop_type` 等預設欄位應與舊欄位分開分析，不能因新增欄位全部有值就宣稱所有敵群玩法都改變。

## 39 筆舊增傷原生化的語意比較

補充調查 S151–S153 對照 r17 實際載入的39筆技能與DGDB同ID及其狀態鏈。r17保留舊參數並新增47狀態列；原生化本身沒有套用DGDB後期平衡。

39筆中36筆的增傷效果在不計持續回合時相同，27筆連持續回合也相同。595角色直接引用其中23筆，19筆增傷狀態相同，另4筆如下；「相同狀態」不等於全部原始欄位相同。

| 技能 ID／名稱 | r17 | DGDB |
| --- | --- | --- |
| 203120 リミッター解除 | 水1.25倍，1回合 | 水1.3倍，1回合；另加全體水屬性15倍貫通攻擊 |
| 203130 作戦提案 | 風1.25倍，1回合 | 風1.3倍，1回合；另將右側3張手牌轉無 |
| 204280 定温保存 | 炎1.25倍，1回合 | 炎1.25倍，3回合 |
| 204490 シェパードtwo | 炎1.2倍，3回合 | 炎1.75倍，3回合 |

其餘8筆狀態／回合差異是編號列204120、204130～204136，由3／4回合改為5回合，當時595角沒有引用。另6筆基礎冷卻27→32也未被當時角色引用；不能把39筆全部描述成玩家使用效果都有變。

r17以技能ID×100＋回合作為自建狀態ID，DGDB則常引用共用狀態。例：技能102000在r17引用10200001、DGDB引用301400，兩者都是光1.5倍1回合、基礎CD27。因此不能只比較 `value0..4` 或只換技能列，必須解析狀態引用。

純增益的 `skill_damage_enable` 在r17為1、DGDB為0；2.9僅在值為2時執行直接傷害，此欄差異不會單獨增加攻擊。203120在DGDB為2且 `skill_power=1500`，才有實際新增攻擊。DGDB狀態表沒有 `clear_type`，r17自建列明確設2；移植仍需補清除規則。

以上是舊內容與後期資料的比較，不是把DGDB值寫回r17的要求；2.9.1／DGDB-1另以DGDB定義為設計基準，見 [版本說明](../v291/playable/README.md)。調查未執行DGDB版Android戰鬥。
