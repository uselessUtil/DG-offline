## 最重要的結論

- 2014 舊內容以 **1.0.6 原表及三月底快取**為基準；快取涵蓋 595 個有效角色，但不等於精確證明備份來自哪個 APK。
- DGDB 是**無印後期彙整**：2,694 個角色、34 張 SQL 表（33 張有資料）。不能以同 ID 直接覆蓋 2014 數值與關卡。
- **1.0.9 是早期矩陣中舊 JSON 不刪欄位直接解析的已測上限，不是離線移植上限。** 2.1.0、[2.4.0](../v240/playable/README.md)、[2.9.0](../v290/playable/README.md) 已有舊內容候選版，各自的受管／Android 驗證範圍不同。2.9.0 的 r13-final 已有47筆新增狀態的整合報告，r14 再修正進化頁對話生命週期；現行 r17 包含存檔備份、固定1.0.6備份單向轉入與取消接續退休，24組受管檢查有既有紀錄，Android 流程仍待驗證。[4.0.0 r16](../v400/playable/README.md) 已有原始 1.0.6 內容候選版與針對性檢查，尚未驗證 Android 與完整流程；[先前 DLL 研究](V400_OLD_CONTENT.md) 的 595 角色快取解析範圍另行保留。
- 舊快取能覆蓋 1.0.6 的 522 個角色原素材、99／101 區模型與門，prototype 20 起已實作原生載入；Android 渲染成功與否仍需實機確認。
- 報告中的舊問題須連同後續版本閱讀：Boss 串接採用備份設定是在 prototype 21；補齊標準五星在 22；新卡獲得時間修正在 22r4；五星三倍在 22r5；目前入口為22r7，新增 Others 存檔匯出／匯入與中斷回復；Android 選檔流程尚未驗證。
- 2026-10-21 的 Android 16／TB323FU 測試只證明指定 prototype 17 **安裝失敗：ABI 不符**。不能延伸為最新版已實機測試，也不能把容器測試當成 Android 遊玩驗證。

1.0.6 的新格式、原生選檔橋接、回復設計與跨版本共用來源限制見 [存檔備份說明](../SAVE_BACKUP.md)。4.0.0 r15 的新增範圍為缺 Link 規則支援、空月登入路由／頁尾提示及線上政策等待；r16 再處理廣告ID背景執行緒造成的Java例外，僅有DEX結構與封裝核對。各項隔離測試不等於 Android 完整流程。

## 保存範圍與證據用法

本文與各章的 `S01` 等編號，對應 `sources.json` 的來源路徑、位元組大小、SHA-256 與收錄用途。來源路徑一律相對倉庫根目錄；`availability=local-only` 表示檔案仍受 `.gitignore` 排除，Git checkout 不附原報告。雜湊用來辨識各次收錄的報告，不代表報告內容已被獨立重新驗證，也不是 APK 的雜湊。

2026-10-25 的本機核對另記於來源清單的 local_source_check：S08、S11、S15、S20–S22、S25、S26、S30、S31、S35、S36 共12份歷史來源目前缺檔，保留原指紋但無法重新核對；不推測移除原因。S29 的維護文件已有更新，原指紋可從 Git revision ce424bb5869a01718e1b156267d66b59f40951ec 讀回，原 SHA-256 不改寫成新內容。本輪共173份來源，159份本機檔案指紋相符、12份缺檔、2份來源已更新；這不是重跑歷史測試。

本次保存人工整理的結論及報告指紋。未搬入 APK、DLL、解包主資料、SQL、圖片、日誌、私人裝置資料或簽署材料，也沒有刪除或搬動原 `artifacts/`。數值與既有測試結果均註明來源／版本；本次僅做靜態語法、文件與來源指紋核對，未重新建置、執行遊戲回歸、連線查詢原站或安裝 APK。

報告中提及的探測程式有些僅保存在 `artifacts/`，且依賴暫存中間檔。本目錄不是完整可重現工具包；要重跑該調查，仍須另備對應來源、原報告及探測程式。已維護的入口見各章，請在依 [倉庫 Dockerfile](../../Dockerfile) 建立的工具環境內、從倉庫根目錄執行，並核對各工具尚未參數化的設定。

已有公開文件的早期圖鑑、CDN、Wiki 與圖片盤點改以連結索引，不重複搬入其大型清單。後續新增調查時應更新相關章節、補上來源指紋，並將「尚未實作」「已實作」「受管測試通過」「Android 實測」分開記錄。
