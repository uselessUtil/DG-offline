# Prototype 提交索引

此索引說明 1.0.6 離線改造的功能拆分，搭配 [實作與移植指南](../OFFLINE_PORTING_GUIDE.md) 查閱。

## 歷史重建範圍

原倉庫將 prototype 1～16 的程式集中在一個提交，沒有保存各版維護原始碼的獨立提交。這次依最終維護來源、既有 APK 及建置／測試紀錄重建功能檢查點；下表不是當時逐版提交的原始紀錄。

共拆成 23 個功能與測試提交。prototype 3 包含 artwork 與 r2 的相容性修正；prototype 13 使用已修正 IL 回傳型別的候選版，不收錄曾被拒絕的無效 IL 候選版。其選單顯示問題仍由 prototype 14 的提交接續修正。共用建置與測試支援包含後來整理的內容，因此中間提交不保證重製出與已交付 APK 位元完全相同的產物。

完成 prototype 16 後的程式、工具及既有文件樹與拆分前一致；後續素材歸檔、圖庫及公開指南的四個提交保留各自內容，只重接父提交。本索引與 README 連結另以文件提交加入。APK、下載素材、產生檔、簽章金鑰與本機約束檔均未納入此次歷史。

## 這次拆分的驗證

prototype 1～16 的重建來源均通過 C# 編譯、IL 修補與參照檢查，以及各階段適用的本地 API、存檔重載與功能回歸測試。額外拆出的地圖／血條及頭像／地板檢查點也分別通過編譯與適用測試，23 個檢查點的 Python 程式均通過語法檢查。這些測試使用引擎替身，不能視為 Android 畫面、觸控或場景生命週期的實機驗證；此次未重建或替換已交付 APK。
