# Divine Gate 離線改造工具

本專案提供 Divine Gate APK 的版本限定補丁、資料與素材盤點工具、測試及移植文件。目前可用範圍、來源需求與 Android 驗證限制見 [離線版說明](offline/README.md)，完整修改位置及其他版本移植方法見 [實作與移植指南](OFFLINE_PORTING_GUIDE.md)。

原 APK、遊戲素材、快取、簽章金鑰與建置產物不隨 Git checkout 提供。重現前須另備版本相符的來源及清單；開發工具在專案 Docker 環境執行，設定見 [Dockerfile](Dockerfile)。
